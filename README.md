# shaperate

Shape color rate values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/shaperate/

## Install / run

```bash
git clone https://github.com/theworker02/shaperate.git
cd shaperate
node src/cli.js
node --test
```
